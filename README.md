# personal-portfolio
**Assignment 10**

A responsive personal portfolio website built to showcase my skills, projects, services, and contact information.

## Features

* Responsive design for all screen sizes
* Dark Mode with theme persistence using LocalStorage
* Multiple color themes
* Multiple font options
* Portfolio projects filter
* Testimonials carousel
* Custom dropdown menus
* Contact form with validation
* Success message using SweetAlert
* Smooth navigation and scroll-to-top button
* Mobile-friendly navigation menu
* Form data handling using JavaScript

## Technologies Used

* HTML5
* Tailwind CSS
* JavaScript
* Font Awesome
* SweetAlert2
* LocalStorage
